Booking Briefing (Agoda) — Privacy Policy

Effective date: 2026-09-16

"Booking Briefing (Agoda)" (the "Extension") is a browser extension that, on Agoda (agoda.com) accommodation booking pages, shows the real total payable including taxes and fees and the estimated loss if you cancel, in a single briefing card. It also scans publicly posted reviews for mentions of hidden costs (city/accommodation tax, deposits, breakfast, facility fees, on-site payments, and similar). This policy explains what information the Extension handles and how.

1. Information collected and processed

TypeContentHow it is handled
Price information Rate, tax and fee items displayed on the Agoda booking page you are currently viewing Read within the browser only, to compute the real total · never sent anywhere
Cancellation policy text Cancellation and refund terms shown on the page Read within the browser only, to compute the estimated loss · never sent anywhere
Public review text User reviews publicly posted on Agoda for the property in question Sent to our classification server to determine whether hidden costs are mentioned (see the note below). Reviews are retrieved by the Extension calling Agoda's own review API; no additional personally identifying information is requested.
Review text is sent to our own server for classification.
The hidden-cost detection feature uses a classification model we trained ourselves, and that model runs on a separate server rather than inside the Extension. For this feature, the public review text for the property is sent to that server as-is (at most 100 reviews per request); only the classification result is returned. The server does not store the review text it receives and discards it immediately after handling the request. Review text may contain personal information such as the name of the author or of a third party (for example, hotel staff); in that case it is likewise discarded immediately after transmission and is not stored separately. If the server cannot be reached, the rest of the Extension (price and cancellation briefing, rule-based review display) continues to work normally.

2. Information not collected

  • Login or account information — The Extension itself has no sign-up or login feature, and does not request or store usernames or passwords.
  • Payment or financial information — No card numbers, account numbers or other payment credentials are collected. The "total" shown on screen is a computed figure for reference only.
  • Names, contact details and other identifying information — The Extension does not separately request any such information.

3. Where information is stored, and for how long

  • Usability values such as computed price and cancellation results and the on-screen position of the briefing card are stored only in the user's browser via chrome.storage.local. They are not synced to any account or cloud service, and are not transmitted to the development team's servers.
  • Text sent to the server for review classification is discarded as soon as the response is generated, and is not stored in a database or anywhere else.
  • In the course of operating the server, basic access records such as client IP address and timestamp may be logged temporarily by the cloud provider (Google Cloud Run). The development team does not separately collect or analyze these records.

4. Disclosure to third parties

We do not provide or sell collected information to third parties for any purpose other than the classification processing described in section 1. We do not use it for purposes unrelated to the Extension's core functionality, such as advertising or credit scoring.

5. Permissions requested by the Extension

PermissionPurpose
activeTabTo read the contents of the current tab (an Agoda page) on which the user has invoked the Extension
sidePanelTo display analysis results in the browser's side panel
storageTo store briefing card state and similar values locally, in the user's browser only
Host permission https://*.agoda.com/*To confine the Extension to Agoda domain pages — it reads and runs nothing on any other site

6. User rights

The Extension maintains no user accounts, so there is no personal account information held on file. If you nonetheless have questions about how data is handled, or wish to request deletion or correction, please contact us at the address below.
