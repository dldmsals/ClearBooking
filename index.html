예약 브리핑 (아고다)

아고다 숙소 예약 페이지에서 세금·수수료를 포함한 실제 결제 총액과 취소 시 예상 손실액을 한 장의 브리핑 카드로 보여주는 크롬 확장 프로그램입니다. 공개된 리뷰에서 도시세·보증금·주차비 같은 숨은 비용 언급도 함께 찾아 알려줍니다.

주요 기능

  • 실제 결제액 — 화면에 표시된 가격에 세금·수수료를 더한 총액을 계산합니다.
  • 취소 손실 타임라인 — 취소 약관을 읽어 "언제부터 얼마를 잃는지"를 날짜별 금액으로 보여줍니다.
  • 숨은 비용 — 예약 화면에 없다가 현장에서 청구되는 비용을 리뷰에서 찾습니다.
  • 표기 모순 — 페이지 설명과 실제 후기가 어긋나면 알려줍니다.
